# Akten als PDF Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ganze Fallakte (Kopf immer, weitere Teile ankreuzbar) und einzelne Berichte als ordentlich formatiertes PDF exportieren.

**Architecture:** Die Datensammlung von `GET /case-files/:id` wird in `loadCaseFileDetail(req, id)` herausgezogen und von Detail-Route und PDF genutzt (gleiche Rechte, gleiche Schalter). Markdown wird mit dem vorhandenen `renderMarkdown` zu HTML und dieses (bekannte, sichere Tag-Menge) von `md-pdf.js` in Blöcke zerlegt, die `pdfkit` setzt. Layout in `src/casefile-pdf.js`.

**Tech Stack:** Node 22, Fastify 5, `pdfkit` (vorhanden), DejaVu-Schriften aus Debian-Paketen im Image.

**Spec:** `docs/superpowers/specs/2026-11-11-fuhrpark-umbuchungen-akten-pdf-design.md` Abschnitt 3

## Global Constraints

- Kopf immer vollständig: Aktenzeichen, Titel, Aktenart, Bereich, Status, Priorität, Ort, Tatzeit, Eröffnet/Abgeschlossen, Sachbearbeitung, beschränkt ja/nein, Sachverhalt. Fußzeile: „Exportiert am <Datum Uhrzeit> von <Name> · Seite x von y“.
- Teile (Schlüssel = Query-Wert `parts`): `people`, `vehicles`, `links`, `entries`, `reports`, `charges`, `evidence`, `warrants`, `images`, `attachments`. Vorgabe im Dialog: alle an. Ausgeschaltete Aktensystem-Teile (`caseFeature`) weder im Dialog noch im PDF.
- In der Akte nur Berichte mit `status='approved'`. Einzelexport: jeder Bericht, den man sehen darf; Entwurf/eingereicht mit großem Vermerk „ENTWURF“ bzw. „NICHT FREIGEGEBEN“.
- Bilder eingebettet (PNG/JPEG, max. Breite der Seite, Bildunterschrift darunter); andere Anhänge nur als Liste (Name, Größe, hochgeladen von/am).
- Rechte nur über `loadFile`/`loadChild` (`casefile-access.js`); jeder Export: `audit(req, 'case_file.exported_pdf' | 'case_file_report.exported_pdf', …, { parts })`.
- Kein neues npm-Paket; `markdown.js` bleibt ohne DOM und unverändert in seiner API.
- Alle Regeln aus `AGENTS.md`; Tests auf `bm-check`.

## Review Focus

- Sehr langer Sachverhalt/Bericht (50.000 Zeichen, lange Tabellen) → mehrere Seiten, Tabellenzeilen brechen nicht über den Rand, kein Hängen.
- Text mit Zeichen außerhalb DejaVu (Emoji) → wird ausgelassen bzw. ersetzt, kein Absturz.
- Bilddatei fehlt im Upload-Volume oder ist beschädigt → Platzhalter „Bild nicht verfügbar“, PDF entsteht trotzdem.
- Beschränkte Akte / fremder Benutzer ruft PDF-URL direkt auf → 404 wie bei der Detail-Route.
- Teil-Schalter ausgeschaltet (z. B. Fahndung) aber `parts=warrants` in der URL → Teil fehlt im PDF, kein Fehler.
